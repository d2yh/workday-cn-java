# docs 文件夹

本文件夹用于存放项目相关的文档（设计说明、变更记录、调研笔记、会议纪要等）。

## 存放规则

所有文档按 **创建月份** 归档到对应的子目录中，目录与文件命名遵循以下格式：

```
docs/yyyyMM/yyyyMMdd-HHmm-${title}.md
```

| 组成部分 | 说明 | 示例 |
|----------|------|------|
| `yyyyMM` | 文档创建时间所在的年月，作为子目录名 | `202608` |
| `yyyyMMdd` | 文档创建日期 | `20260829` |
| `HHmm` | 文档创建时间（24 小时制，精确到分钟） | `1640` |
| `${title}` | 文档标题，使用英文小写短横线（kebab-case），不含空格 | `maven-central-publish-plan` |

### 示例

```
docs/
├── 202608/
│   ├── 20260829-1640-maven-central-publish-plan.md
│   └── 20260831-0930-holiday-data-source-comparison.md
└── 202609/
    └── 20260905-1415-v1.1-release-notes.md
```

## 约定

- 文档一律使用 Markdown（`.md`）格式。
- 文件创建后 **不再移动或重命名**，即使内容后续有更新，路径仍保留创建时的时间戳，以便按时间线追溯。
- 新文档放入当前月份对应的 `yyyyMM` 子目录；目录不存在时先创建。
- 与代码强绑定的说明（如构建、开发指南）仍放在仓库根目录，本文件夹只收录时间性文档。
